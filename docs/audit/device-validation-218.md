# Physical-device release gate (not executed)

Install over build 76 on OnePlus 6T and TCL Google TV; do not uninstall or clear data. Before and after: record APK version/certificate, role, camera and Clock settings, saved TV identities, roster dates, alarm configuration and eCrew login availability. Pass only if existing settings and tokens survive and lite TV does not load Gecko/MediaPipe.

1. Clock: leave dashboard and full Clock visible beyond system timeout and each Away/dim interval. Expect dim/black as configured, no device lock while visible. Background Mirror: normal OS locking must resume. Test Dream settings and internal Clock navigation.
2. Gestures: at 4/8/12 ft, daylight/dim, one/two people, CPU/GPU and ECO/preactivation/active. At thresholds 50/65/85/90/95, verify deliberate one-second palm claim, no claim without palm, no phantom command on dropout/crossings, household takeover, exit/return, recenter, all 30/60/120/300-second expiries and re-palm. Exercise thumb OK/Back, Victory Home, index navigation/repeats, shortcuts, legacy mappings. Record failures separately by engine; do not combine success rates.
3. Recovery: disconnect/reconnect Wi-Fi, turn TV off/on, change address, rotate/switch camera, deny/regrant permission, foreground/background/lock phone, trigger supported delegate fallback. Cancel each pairing stage and start another. Expect no old token/TV identity overwrite, no queued command replay, bounded recovery and no ANR. Check TV feedback fade/hide and app launches.
4. Capture anonymized timing summaries: camera FPS, actual model/hand capacity, input/crop size, thermal state, delegate, p50/p95 observation-to-write latency, stale/queue drops. Copy the CPU wake-lock held/released duration and acquisition count from diagnostics (service lifetime only). Measure idle/active CPU, wake-lock duration and battery drain under matched brightness/network/temperature over at least 30 minutes, baseline vs candidate. No battery improvement claim without measurements.
5. eCrew: manual login then close/reopen/process restart; saved password restricted to exact HTTPS site. Explicit logout and local-clear failure/retry must report accurately. Offline last-good roster remains accessible. Import valid same-crew overlapping and new periods; malformed/unsupported/truncated PDFs; wrong-crew PDF in foreground/background. Rejected imports must not change PDFs, roster, alarms or notifications. Intentional account switch requires confirmation.
6. Alarms: calendar/departure/roster alarms across Manila midnight, overseas DST change, timezone change, stale/offline calendar, reboot, exact-alarm denied/granted and notification denied/granted. Check expected trigger instant and no duplicate alarm after update.
7. Streaming: two viewers plus status/pairing, slow clients, low memory, long compressed delay, repeated stop/start and Wi-Fi loss. No corrupted/reused rendered bitmaps, growing memory, unbounded retries or stalled pairing. Test existing HTTP and third-party IP Webcam independently from any secure-channel support.

No-go: changed certificate/application ID, loss of persisted data or pairing, false logout/import success, wrong-crew replacement without confirmation, phantom/replayed keys, persistent lock while Clock visible, unbounded resource growth, or failure of either flavor's automated release gates. Keep candidate unpublished until these checks and outstanding architectural/administrative decisions are resolved.
